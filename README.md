Este repositório contém a resolução de exercícios, desafios de código e projetos desenvolvidos durante o **Bootcamp Itaú - Java com Inteligência Artificial**, promovido em parceria com a **DIO (Digital Innovation One)**.

---

## 📌 Sobre o Bootcamp

O bootcamp tem como objetivo acelerar o aprendizado em desenvolvimento backend com Java, cobrindo desde os fundamentos da linguagem até conceitos avançados de Programação Orientada a Objetos (POO), estruturas de dados e a integração de aplicações Java com soluções de Inteligência Artificial.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

- **Linguagem:** Java (JDK 17+)
- **IDE:** VS Code / IntelliJ IDEA / Eclipse
- **Controle de Versão:** Git e GitHub
- **Conceitos:** Lógica de Programação, POO, Estruturas de Dados, Inteligência Artificial.
